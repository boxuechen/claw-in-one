# Code of conduct

We want collaboration here to be technically rigorous, welcoming, and safe.

- Be respectful and specific. Critique code and decisions, not people.
- Assume good intent while still asking for evidence and reproducible results.
- Do not harass, threaten, discriminate, publish private information, or use
  sexualized or exclusionary language.
- Respect security embargoes and remove secrets from logs and examples.

Maintainers may edit or remove content and restrict participation when these
expectations are violated. Report sensitive conduct concerns privately through
the repository's GitHub private vulnerability reporting channel; do not expose
the affected person in a public issue.
