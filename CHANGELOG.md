# Changelog

## 0.1.0-alpha.1 — Unreleased

First public Alpha of ClawInOne:

- run a pinned OpenClaw Gateway in Android's official AVF Debian environment;
- build Kotlin, NDK, Flutter, Godot, React Native, and Web projects on the phone;
- inspect, install, launch, and update generated Android APKs on the same phone;
- present Android workloads through the built-in scrcpy-based VScreen;
- observe and operate explicitly authorized Android apps through Android Use;
- use the same managed Debian environment through the built-in Terminal.

The retained validation baseline is Pixel 8 on Android 17. Broader Pixel support,
clean-device onboarding certification, Android Chrome CDP automation, and stable
distribution remain future work.
